# senior-thesis-aarp-housing
Data and code for senior thesis examining the relationship between AARP Age-Friendly Network participation and elderly housing cost burden (at the county level).

# Data
Most of my data was from the Census Bureau (5-year ACS) and other public government websites. The list of AARP age friendly communities was taken from the AARP website manually. As of April 2026, there were 298 counties that joined the AARP Age-Friendly Network. The full dataset used in this project exceeds GitHub's web upload limits so I've added a google drive link instead. 

Data can be downloaded here:
[https://drive.google.com/file/d/1bZ3qctcxWiwszHJeobxmhDuFbUAIpRQG/view?usp=sharing]
